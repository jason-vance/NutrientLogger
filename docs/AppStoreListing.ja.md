## Description
Nutrient Loggerは、食べ物に本当は何が入っているのかを知りたい人のための、オフラインファーストの栄養トラッカーです。カロリーとマクロ栄養素だけでなく、体に必要なビタミン・ミネラル・アミノ酸をまるごと記録できます。

クラウド型のトラッカーと違い、あなたの食事記録が端末の外に出ることはありません。マクロ中心のアプリと違い、1回の記録ごとに80種類以上の栄養素を分析するので、本格的な欠乏になる前に不足に気づけます。

主な機能：

* 詳細な栄養素の内訳
タンパク質や食物繊維からマグネシウム、ビタミンB12まで、マクロ・ミクロ両方の栄養素の1日の摂取量を確認。気になる栄養素を選んで並べ替え、自分の目標に合った栄養タブを作れます。

* バーコードスキャナー
市販食品のバーコードをスキャンするだけで栄養データを即取得。認識できないバーコードでも、手動検索やカスタム食品の追加で記録を止めません。

* 充実の食品データベース
生鮮食材から市販品まで数万件の食品から検索して、食事を正確に記録。スマート検索があなたの意図を理解し、目当ての食品をすぐに見つけます。

* なんでも記録
バーコードスキャン、データベース検索、オリジナル食品の追加に対応。よく食べる食事を保存しておけば、次回はさらに素早く記録できます。

* パーソナライズされた目標
カロリー・マクロ・微量栄養素の目標を自分で設定するか、年齢と性別に基づく推奨量を利用できます。カロリー・マクロ・水分のトレンドグラフと各栄養素の記録で、進捗を確認しながらバランスを保てます。

* 水分トラッキング
ワンタップで水分を記録し、アニメーションのトラッカーが1日の目標に向かって満ちていくのを楽しめます。7日間・30日間の水分トレンドも確認できます（プレミアム）。

* 体組成の記録と目標（プレミアム）
体重・体脂肪率・BMI・ウエストから、気になる項目を選んで記録。目標と期限を設定すると、必要なペースの計算、推移の予測、BMR/TDEEに基づくカロリー目標の設定まで行います。

* ストリークと実績
毎日の記録ストリークと週間の体組成ストリークを積み上げ、節目ごとにお祝い。最長ストリークや記録日数の合計などはプロフィールで確認できます。

* 栄養素トレンドグラフ（プレミアム）
どの栄養素でも、7日間・30日間の摂取量の変化をグラフで確認。パターンの発見、継続の確認、目標との比較に役立ちます。

* 週間欠乏インサイト（プレミアム）
不足しがちな栄養素を週1回のダイジェストでお知らせ。不足を補うのに役立つ食品も提案します。

* Appleヘルスケア連携（プレミアム）
毎日のカロリー・タンパク質・脂質・炭水化物・水分をヘルスケアに自動書き込み。体重データをヘルスケアから読み込んで、すべてを一か所にまとめられます。

* CSVエクスポート（プレミアム）
任意の期間の食事記録を栄養データ付きで書き出し。医師や管理栄養士との共有に最適です。

* 記録しながら学ぶ
それぞれの栄養素が体にどう働き、健康になぜ大切なのかを学べます。

Nutrient Loggerは、栄養に真剣に向き合うすべての人にぴったりです。特定の食事法を実践中の方も、栄養不足が気になる方も、自分の健康にちょっと興味がある方も。カロリーの先へ進んで、食事を本当に理解しましょう。

## What's New (v4.1)
• 食事画面を刷新：1食ごとに1枚のカードで表示し、すべての食事枠を常に表示。1日の様子がひと目でわかります
• 食事に直接食品を追加——日付と食事の時間帯は自動で入力済み
• 新しい上限アラート：「今週摂りすぎ」カードが、不足している栄養素と並べて、摂りすぎの可能性がある栄養素を表示します
• プログレスバーとカロリーリングが、目標や上限を超えたことをはっきり表示するようになりました
• ナトリウムが常に目標の0%と表示される問題を修正
• そのほかのバグ修正と磨き込み
